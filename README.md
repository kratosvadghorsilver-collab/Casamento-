# Website – Casamentos Prematuros

Site multipáginas sobre casamentos prematuros, pronto para publicar no GitHub Pages.

## Ficheiros (tudo na mesma pasta)

```

├── desenvolvimento.html
├── solucoes.html
├── recomendacoes.html
├── conclusao.html
├── referencias.html
├── style.css
├── main.js
├── logo-escola.png
├── sala-aula-1.jpg
├── sala-aula-2.jpg
├── sala-aula-3.jpg
└── README.md
```

**Não tem pastas** – é só arrastar todos os ficheiros de uma vez para o GitHub.

## Como publicar no GitHub Pages

1. Crie um repositório novo (ex: `casamentos-prematuros`)
2. Arraste **todos** estes ficheiros de uma vez
3. Vá a **Settings → Pages**
4. Source: Deploy from a branch → `main` → `/ (root)`
5. Guarde e aguarde 1–2 minutos

O site ficará em:
`https://SEU-USUARIO.github.io/casamentos-prematuros/`
